#  JobMailer Pro

A professional Node.js email automation tool for sending personalized job application emails with HTML templates and resume attachments.

## ✨ Features

- HTML Email Templates
- Resume Attachment
- Personalized Emails
- CSV Support
- Excel Support (In Progress)
- Gmail SMTP
- Email Validation
- Duplicate Detection
- Success Logs
- Failed Logs
- Modular Architecture

## 📂 Project Structure

```
JobMailer
│
├── attachments
├── config
├── data
├── logs
├── templates
├── utils
├── index.js
├── package.json
└── README.md
```

## ⚙ Installation

```bash
npm install
```

Create a `.env` file

```
EMAIL=your_email@gmail.com
APP_PASSWORD=your_app_password
```

Run

```bash
node index.js
```
